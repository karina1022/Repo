## 目前功能

1. 接收紅外線訊號
     - 目前只用 PB0 當作 IR 接收腳位。
     - 採用類 NEC 的 6-bit 封包格式。
     - 會先檢查時序與 CRC，再確認同一封包連續出現 2 次才算有效。

2. 辨識事件種類
     - SAFE
     - VRU Level 1、Level 2、Level 3
     - BRAKE 
     - SYSTEM ERROR

3. 控制板上 LED 顯示
     - 用 TIM4 的 PWM 控制 PD12～PD15。
     - 不同事件會顯示不同顏色或閃爍方式。
     - SAFE 和錯誤狀態會讓 LED 熄滅。

4. 控制 DFPlayer 播放語音
     - 透過 USART2 與 DFPlayer 通訊。
     - 事件發生時會播放對應語音，或在特定情況下停止播放。
     - 音量目前設定為 22。

5. 送出監控文字到電腦
     - 透過 USART3 輸出事件名稱。
     - 例如 SAFE、VRU_LEVEL1、BRAKE_LEVEL3、ERROR。

6. USB Host 背景運作
     - 目前有初始化 USB Host 與 CDC 類別。
     - 會持續跑背景流程，但尚未實際拿來傳資料。
